## 0. الخلاصة التنفيذية

**نقاط القوة الحالية (ميزة تنافسية حقيقية):** تقطيع/Nesting للصاج والقطاعات مع البواقي، BOM بارامتري بالطول، ربط عرض سعر → أمر بيع → أمر شغل → فاتورة، قيود يومية آلية، ETA فاتورة إلكترونية، شهادات إتمام وضمان، خدمة ميدانية. **لا يوجد منافس محلي (دفترة، إدارة، قيود) يستهدف الـ Job Shop** بهذا العمق — ودي الفرصة.

**الفجوات الكبرى بالترتيب:**
1. **أخطاء صحة بيانات (Bugs) في التكلفة والمخزون** — لازم تتصلح قبل أي ميزة جديدة، لأنها بتطلّع أرقام غلط للعميل.
2. **ثغرة أمنية حرجة:** `/auth/signup-internal` مفتوح بدون توثيق — أي حد يقدر ينشئ tenant (تم التحقق: `app/api/auth.py:313`, `app/core/tenant_middleware.py:14-23`).
3. **أساسيات التصنيع الناقصة:** Product master للمنتج التام، كمية للتجميعات الفرعية، وحدات قياس وتحويل، مراكز عمل + routing، تكاليف غير مباشرة، إغلاق فترات، عملات أجنبية، تكاليف استيراد (Landed cost).
4. **امتثال مصري ناقص:** إيصال إلكتروني B2C، نموذج 41 خصم وإضافة، تأمينات اجتماعية قانون 148/2019 وضريبة كسب العمل، إضافي بأجر مضاعف، نظام المشروعات الصغيرة (قانون 6/2025).
5. **ما يطلبه المشتري المصري للفوز بالصفقة:** واتساب حقيقي، تطبيق موبايل/تابلت لأرضية المصنع، PDF عربي، صيانة وقائية للماكينات، استيراد Excel.

## 4. السوق والتموضع (ملخص البحث)
- **أودو** (~9–14$/مستخدم/شهر + شريك تنفيذ مكلف)، **ERPNext** (مجاني + موصل ETA مدفوع)، **SAP B1 / Dynamics BC** (80–250$ — للشريحة الأعلى).
- **المحليون** (إدارة، دفترة، قيود، أونكس): رخاص لكن تصنيعهم "تكاليف" وليس Job Shop؛ شكاوى من ضعف الموبايل والتصنيع في إدارة.
- **ما يحسم الصفقة:** الربحية لكل أمر/عميل، تطبيق موبايل للورشة والمالك، واتساب، تقارير عربية، سعر ثابت بالجنيه، إعداد سريع بدون شريك.
- **فرصة التميّز الأقوى:** *تسعير بالذكاء الاصطناعي من الرسم (PDF/DXF)* → استخراج الأبعاد والخامات → حساب طول القص وكفاءة الـ nesting (موجود عندكم) → تسعير من أسعار المعادن اللحظية. لا يوجد منافس عربي يقدّمه.
- لاحقاً: مساعد عربي ("أنهي أوامر بتخسر؟")، OCR لفواتير الموردين، حساسات بسيطة لوقت تشغيل الماكينات وصيانة بالاستخدام، بوت واتساب لحالة الطلب والضمان.

## 5. خارطة طريق مقترحة

**الموجة 0 — إصلاح (1–2 أسبوع):** S1–S4، A1–A9، I1–I10، W1–W3. أي رقم تكلفة أو ربحية يطلع للعميل حالياً غير موثوق.

**الموجة 1 — أساسيات المصنع (P0):** Product master وMTS، كمية التجميع الفرعي، إكمال جزئي، وحدات القياس، إصلاح MRP (أوامر شراء مفتوحة + حد طلب)، سجل ماكينات ومراكز عمل مع معدلات تحميل overhead، تسجيل وقت العامل لكل عملية مربوط بالتكلفة، إغلاق الفترات، Landed cost + مرتجع مشتريات + مطابقة ثلاثية، فحص استلام + حجر، تسليم جزئي مربوط بأمر البيع، إيقاف ائتمان، رواتب بالتأمينات وكسب العمل.

**الموجة 2 — ما يتوقعه السوق (P1):** عملات أجنبية، صيانة وقائية، تشغيل لدى الغير، routing وجدولة، إصدارات BOM، مستخلصات بمحتجزات، CPQ بهامش، WhatsApp API + PDF عربي، تطبيق تابلت/PWA للورشة، أجر بالقطعة، NCR/CAPA وشهادات اللوت، صلاحيات دقيقة، استيراد Excel، KPIs تصنيع، الإيصال الإلكتروني ونموذج 41 وقانون 6/2025.

**الموجة 3 — التميّز:** التسعير بالذكاء الاصطناعي من الرسم، MRP متعدد المستويات وجدولة بطاقة محدودة، OEE وحساسات IoT، بوابة العملاء وبوت واتساب، API عام وwebhooks، تعدد الفروع.
